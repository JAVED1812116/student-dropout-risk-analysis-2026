# Student Dropout Risk Analysis 2026

## Project Overview
This project analyzes university student data to identify factors associated with student dropout risk.

## Objectives
- Identify students at risk of dropping out.
- Analyze dropout rates by course type.
- Calculate academic performance indicators.
- Analyze GPA trends.
- Build a student risk score.
- Analyze GDP per capita and dropout rates by continent.

## Technologies
- Python 3.12
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

- `student_dropout_analysis.ipynb` — Main project notebook.
